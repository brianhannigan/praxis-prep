# Praxis 5164 – Core Framework Cheat Sheet

## 📊 Statistics: Transformation Rules

### SHIFT (Add/Subtract a constant)
- Mean → changes by that constant
- Median → changes by that constant
- IQR → **no change**
- Standard deviation → **no change**

### STRETCH (Multiply/Divide by k)
- Mean → × k
- Median → × k
- IQR → × k
- Standard deviation → × |k|

### Outliers
- Mean is sensitive to outliers
- Median is resistant to outliers

---

## 📐 Geometry: Scaling Rules (Dilation)

If scale factor = k:
- Perimeter (1D) → × k
- Area (2D) → × k²
- Volume (3D) → × k³

---

## 🔢 Algebra: Discriminant Rule (Quadratics)

For: ax² + bx + c = 0  
Discriminant: D = b² − 4ac

- D > 0 → 2 real solutions (crosses x-axis twice)
- D = 0 → 1 real solution (touches x-axis)
- D < 0 → 0 real solutions (no x-intercepts)

---

## 📈 Functions: Quick Recognition
- Linear → constant difference
- Exponential → constant percent change
