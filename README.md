## How to Use
1. Open your target test folder under \	ests/\.
2. Start with the **framework cheat sheet** (daily).
3. Do **terminology drills** (10–15 minutes/day).
4. Run **timed practice**, then log misses in \practice-log.md\.
5. Repeat: diagnose → drill → simulate → review.

## Score Strategy
Top-percentile performance requires:
- fast recognition (terminology)
- correct framework selection (no rule-mixing)
- disciplined pacing
